# CountLoop

This repository contains the project page for the paper **"CountLoop: Iterative Agent Guided High Instance Image Generation"**.

## Preview

Open `index.html` in your browser to explore the research portfolio, which includes:

- Abstract and key features
- Visual results and benchmark comparisons
- BibTeX citation for referencing the work

## Local Development

To preview the page locally with a simple web server:

```bash
python -m http.server
```

Then navigate to [http://localhost:8000](http://localhost:8000) in your browser.
